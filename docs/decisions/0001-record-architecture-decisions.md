# 1. Record architecture decisions

**Status:** accepted · 2026-08-17

## Context

This project has several decisions whose reasoning is not obvious from the code,
and which future contributors (human or agent) will otherwise re-litigate.

## Decision

Use lightweight ADRs. One file per decision, numbered, never edited after
acceptance — superseded by a new record instead, with a link both ways.

## Consequences

A short paper trail. The cost is a file per decision; the benefit is not
re-arguing the same points in six months.
